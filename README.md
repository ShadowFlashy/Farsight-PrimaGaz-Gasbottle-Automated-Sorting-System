# bottle-tracking

Detecting and tracking (Primagaz) gas bottles with YOLO (Ultralytics).

- `scripts/`: detection / tracking scripts and `download_commons.py` (downloads the Commons photos)
- `data/commons/`: freely licensed gas bottle photos to label, with author + license per photo in `attribution.csv`
- [docs/DATA.md](docs/DATA.md): all data sources we found (labeled datasets on Roboflow, videos, licenses, notes)
